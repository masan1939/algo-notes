## 复盘模板

```markdown
# 2026-11-22 江西八校集训联盟第三场入门赛

- 链接：https://www.nowcoder.com/acm/contest/144149
- 排名 / 得分：

- 未解：D E

## 时间线
- 00:00-00:10 读了 A~C，A 秒了
- 00:10-00:50 卡在 D，思路是 xx
- ...

## 卡在哪
- D 题：想用暴力，但 n 到 1e5 会超时，没意识到是 xx
- E 题：根本没读

## 赛后补题
- [ ] D —— 补完后记录关键点
- [ ] E

## 一句话教训
```
